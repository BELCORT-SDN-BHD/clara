### ADR-022 — The Wave-A daily-loop design contract (Phase 4 opens)
**Decision:** Phase-4 Wave A is ratified as `docs/plan/wave-a-daily-loop-contract.md` v1.1 + `wave-a-migration-0011-design.md` v1.1: twelve grill rulings **WA-R1..R12** (AP-only scope with aliases + identity-equivalence merge; three-lane DB-gated confidence ladder READY/NEEDS-REVIEW/NEEDS-YOU with qualitative labels; an event-driven `autoDraft_v1` sweep — drafts only, one bill per task, reserve-first token budgeting, receipt-based bookkeeper+ acknowledgement; one cross-client firm review queue subsuming the notification inbox; routine-only batch approve via a dedicated `approve_routine_entry` that structurally refuses high-stakes; doc_review split-view with honest no-region degradation; dual-source human-signed sticky KB rules over transactional per-sighting evidence; scoped open-question objects with a serialized CLR26 approval gate; DB-computed document-baseline diffs over a new append-only revision-snapshot table; gross-to-expense stands for SST supplier bills) plus five review deltas **WA-D1..D5** (the egress lane-carve — OCR is firm-gated because it structurally precedes client attribution, per-client consent gates invoice_facts with an every-active-filing rule and a last-boundary recheck; the sweep runs the coding model; merge never rewrites posted lines and never crosses differing registrations; a signed rule resolves account-choice uncertainty ONLY; approving a high-stakes agent-made draft requires the approver's recorded attestation). **Two supersessions:** WA-R2 supersedes the S6-R1 RPR-only constraint — the owner declared the C6/consent material handled, confirmed and valid (2026-07-21) — and WA-R7 boundedly reopens the §11 batch-approve deferral. New error codes CLR26–29; a new `autodraft` agent-task kind + wake_kind with an exact five-fn allowlist; migration 0011 opens with the AB-3 `engine_kind` pin.
**Why:** The full house ladder ran at design stage: owner grill (12 rulings playback-ratified) → dual design review (native FLAWED, 13 findings; Codex xhigh FLAWED, 24 findings — 8 CRITICAL, independently converging on four defects and adding six more incl. a posted-line-immutability violation in the v1.0 merge design and a consent-revocation replay hole) → a 10-probe empirical battery on a fresh throwaway PG16 (10/10 SUPPORTED — incl. live proof that a high-stakes agent draft was approvable by one bookkeeper with no attestation, the WA-D5 motivation, and that the existing token admission is chat-only read-then-act, so the sweep's reserve-first primitive is genuinely new) → one consolidated owner delta-ratification. v1.0 was not safe to hand to a build lane; every defect was caught before a line of code. Evidence: `docs/plan/research/wave-a/{design-review-native,design-review-codex,design-probes}.md`.
