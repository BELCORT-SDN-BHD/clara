### ADR-035 — The Wave-B dashboard surfaces + pre-ceremony runtime lanes BUILT; the freeze-lint gains the deploy-lock; merged undeployed (2026-07-24)
**Decision:** The Wave-B **dashboard surface** (queue/lint card + catalog parity gate · onboarding/interview panel + the `create_firm` handshake + plan page · the carry-down workbench with the K5 compound-acknowledgment serializable ceremony · the seeding tick-list) and two **pre-ceremony runtime amendments** (the typed interview `/state` v2 + commit op_key; the opening-parse/seeding-prepare document lanes + the `wiki_fact` deterministic dispatch) are **BUILT and merged undeployed** (PR #71). Ceremony artifacts ready: `packages/db/deploy/wave-b-0017-ceremony.sql` + `docs/ops/wave-b-ceremony-runbook.md` (owner-`!`-gated). **Why (recorded lessons):** (a) **The Socratic-debate stage caught missing-caller scope gaps a green build hides** — the runtime-granted fn inventory must be swept for callers whenever a wave ships grants. (c) **A mechanical gate stricter than its written law eventually blocks lawful work** — the freeze-lint's merged==frozen over-approximation was refined to the deploy boundary WITH a monotonic lock, and the refinement was attacked by both reviewers before shipping. (d) Keyed fixed-asset seeding is structurally impossible in 0017 (`seed_fixed_asset` derives its resolution only from a tie document) — an as-built truth the UI now states honestly; the 0018-candidate list (settled plan §3b) consolidates every such follow-on for one future ruling.
