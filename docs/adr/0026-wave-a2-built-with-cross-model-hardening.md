### ADR-026 — Wave A2 (AR + MyInvois XML + bounded auto-post) BUILT + MERGED; six-round cross-model adversarial hardening (2026-07-22)
**Decision:** Wave A2 is BUILT and MERGED to `main` (PR #42, `a4785e9`) — migration `0015_ar_myinvois_rules.sql`; runtime (UBL local-parse via `fast-xml-parser` + the `local_facts` and rule-post matcher-pattern consumers + Azure mapper v5); dashboard (the `rule_post_receipt` card, the XML structured-doc view, the `/rules` surface); and the `packages/backup` R2 off-site backup app (scaffold). It realizes the sales-invoice/AR side, MyInvois UBL file-upload as a **local no-egress** structured engine, the SST 3-leg sales split, CN/DN posting, and **PURCHASE-ONLY** human-signed bounded auto-posting. Deferred to **Wave A2.1**: sales-direction autopost, purchase-side SST 3-leg, and credit-side sightings. **NOT YET DEPLOYED to live** (live Supabase still at 0014; the deploy ceremony is owner-`!`-gated).
**Why:** The house ladder ran through build (interface-pins → five contract-blind lanes → integration) then an as-built **cross-model** review (native `/code-reviewbymatt` + a Codex adversarial lane). The native lane rated the security spine sound; the Codex adversarial lane independently found the build **FLAWED — including a real auto-post MONEY-LAUNDERING path the native lane missed**. A **six-round adversarial ratchet** closed every confirmed finding, each round re-verified until Codex returned **RESOLVED** (final sweep: no remaining money-movement or attribution bypass): laundering closed structurally via a **count/identity leg enumeration + a corroboration-required gate** (replacing a gameable sum-tolerance); type_code→polarity binding; `sst_output` sales-only; the DB **rejects** conflicting/blank duplicate facts (chr(1) sentinel) rather than min-selecting; direction match on name+registration with abstain-on-contradiction; cross-kind counterparty merge forbidden; consolidated e-invoices non-attributable + a reserved-sentinel-TIN guard; the UBL parser hardened into a real namespace(by-URI)/schema/type boundary; XML rendered as escaped text (no XSS); the backup app's silent-truncation / fail-open-dead-man / plaintext-PII defects closed; the new-writers PUBLIC-execute leak closed. Every finding carries a fail-pre/pass-post regression proof. Final gates: db rig 468/0/15, runtime 256/0, dashboard 68/0, typecheck/build/freeze/leak/frozen-lockfile clean; CI green. Ratified design = ADR-025 / `docs/plan/completed/wave-a2-ar-myinvois-contract.md` v1.0. Evidence: `docs/plan/research/wave-a2/` + `.tmp/wave-a2-build/` (LANE/FIX/INTEGRATION notes + the six `codex-reverify*` reports). **Recorded lesson:** a true cross-model adversarial pass caught a money-movement hole a same-model review rated sound — cross-model adversarial review before merging money-touching auto-post is now house practice.
