### ADR-021 — The repository moves to the company organization (BELCORT-SDN-BHD)
**Decision:** `clara` is transferred from the personal account `mosaladtaooo` to the company organization **`BELCORT-SDN-BHD`**, via the intermediate personal account `belcorttao` (a two-hop transfer: `mosaladtaooo` → `belcorttao` → org). The **agent's operating identity becomes `belcorttao`**, not the personal account: `mosaladtaooo` is removed as a collaborator rather than retained, so no personal account holds standing write access to the firm's accounting-system repository. Old URLs redirect indefinitely and **issue/PR numbers are preserved**, so every `#NN` reference in this log and in `CLAUDE.md` remains valid — nothing is renumbered. Historical ADRs that name the old slug (ADR-001) are **left intact**: this log is append-only and supersedes rather than rewrites.
**Why:** (1) **Billing.** GitHub Actions minutes are metered for private repos and bill the repo OWNER. The personal account's allowance was exhausted mid-session (CI hard-blocked: *"recent account payments have failed or your spending limit needs to be increased"*), which stopped the binding merge gate dead. The org carries the company payment method, so CI billing moves with the repo. (2) **Custody.** A production accounting system holding a real firm's statutory books should not be owned by an individual's personal GitHub account; ownership belongs with the company that carries the professional liability. **Verified before the move** (read-only): zero Actions secrets, variables, environments, webhooks and deploy keys — nothing to re-create; no GitHub↔Vercel git integration (the dashboard deploys by CLI from a local link, `.vercel/project.json`, gitignored) so no deploy pipeline breaks; CI hard-codes no owner and no secrets; exactly one FUNCTIONAL reference exists (the git remote), the rest are documentation. **Costs accepted:** a seat-limited org meant retaining `mosaladtaooo` as an outside collaborator would have consumed a paid seat — declined in favour of the cleaner identity; the agent's tooling (gh CLI, git credential helper, and the GitHub MCP token) re-authenticates as `belcorttao`. **Residual:** branch protection remains unavailable on this plan tier for private repos (a Free org does NOT unlock it — only Team does), so `main` is PR-only by convention plus the git-base freeze-lint and CI, exactly as before; revisit if the org moves to Team. Two org policies must stay compatible or CI breaks silently: an allowed-actions allowlist would reject `actions/checkout@v4`, and enforced SHA-pinning would reject `@v4` tags.
