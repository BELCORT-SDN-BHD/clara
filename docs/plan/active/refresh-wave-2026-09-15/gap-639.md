今天真正能生出登记行的，只有单据／人工／期初这三条走 `_subledger_on_approve` 的老车道。0041 自己的注释还写着

其余三件事仍然缺：一、AC3 要的"依赖型有版本追问"在 Work 车道上没有出口（`ask_question` 没有 `execute`，是**工作流本体**

## Frozen-body verdict

**`touches_frozen_closure: false`** — on the recommended cut, and conditionally.

The acquisition half needs **no** frozen change if the birth is moved to a **deferred constraint trigger** on `clara.journal_entries` (option B below): every lane including the Work lane's raw `UPDATE` is then covered, no workflow file moves, and no pinned body is recut. What the first draft of this map argued — "the run never sees the asset, so nothing has to move" — was right in its conclusion and wrong in its reason: the run never sees the asset because **the asset is never born**.

Two corrections to the reasoning that mattered:

1. **The precedent proves capture, not safety.** `packages/runtime/lib/periodic-adjustment-basis.ts` is in `frozen-workflows.json` today with `deployed: true` and the note "frozen **BY CLOSURE**", contradicting `643-final.md:66` which called it "not in frozen-workflows.json". `scripts/check-frozen-workflows.mjs:417-433` (IMPORT-ESCAPE) forces the relative import that captures any first-party module a frozen body imports.
