# Full frontend flow and evidence coverage — issue 610

**Checked:** 2026-09-08  
**Status:** initial whole-product coverage map for [补齐全量前端用户流、交互状态与 Mobbin 对照](https://github.com/BELCORT-SDN-BHD/clara/issues/610). It is a research inventory, not proof that the frontend or backend gaps are implemented. Its completed flow contract will hand off to the implementation plan in [issue 605](https://github.com/BELCORT-SDN-BHD/clara/issues/605).

## Method and evidence scale

The repository graph supplied route/component discovery and coverage metadata; every current route claim below was checked against the filesystem because `apps/web` metadata has changed since the index generation. The current tree has 30 page files including the E2E harness: 9 entry/auth/admission pages, 18 firm/client pages, two full-screen Clara thread pages, and the harness. The accepted target also contains destinations with no current page, especially Work and its detail, account/firm/billing settings, separate AR/AP, Assets, Plans and Accounts views.

- **C2** — current route and principal page actions inspected; **C1** — current source exists but the end-to-end surface is partial; **C0** — no conforming current surface/read model found. These are frontend discovery grades: they do not claim every called SQL/function/provider was traced.
- **M2** — complete bounded static Mobbin sequence inspected; **M1** — one or more specific static frames inspected; **M0** — no relevant Mobbin frame inspected. Static frames prove visible composition only, never backend correctness, motion, keyboard behavior, recovery or permissions.
- **P1** — synthetic runnable prototype exists for part of the flow; **P0** — no flow prototype. A prototype is not production integration evidence.

Every implementation slice must additionally prove desktop and narrow layout, keyboard order, focus and restoration, 200% zoom, reduced motion, live permission changes, retry/idempotency, and the stated empty/partial/error paths. Those cross-cutting checks are not repeated as if already verified in every row.
